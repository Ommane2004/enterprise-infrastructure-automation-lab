# Enterprise Infrastructure & Automation Lab

A production-inspired enterprise infrastructure lab designed to demonstrate
practical skills in network engineering, system administration, automation,
monitoring, cybersecurity, troubleshooting, and incident response.

## Objectives

- Build and operate a multi-system enterprise-style lab
- Design segmented network infrastructure
- Administer Linux and Windows systems
- Implement infrastructure automation using Ansible
- Develop Python automation for infrastructure operations
- Monitor infrastructure using Zabbix
- Implement security controls and monitoring
- Simulate infrastructure failures and incidents
- Troubleshoot problems using structured root-cause analysis
- Document configurations, decisions, failures, and lessons learned

## Core Technologies

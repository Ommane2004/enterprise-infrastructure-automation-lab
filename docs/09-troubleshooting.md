# Troubleshooting

## Overview

Troubleshooting in this lab follows a structured, evidence-driven approach.

The objective is not simply to make a system work again, but to:

- Identify the actual fault domain.
- Collect evidence before changing configuration.
- Test hypotheses systematically.
- Apply the smallest appropriate correction.
- Validate recovery.
- Document the result.

---

# Runbook: Server Failure

## Purpose

This runbook provides a structured procedure for investigating an unavailable or degraded Linux or Windows server.

It is intended for incidents involving:

- Host unreachable
- Zabbix agent unavailable
- Server resource issues
- Operating-system problems
- Remote-management failure
- Service availability problems
- Unexpected server shutdown

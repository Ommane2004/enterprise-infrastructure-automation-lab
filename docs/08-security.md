# Security

## Overview

The security portion of this lab is designed as an isolated environment for learning defensive security, controlled security testing, network analysis, web-security concepts, detection engineering, and incident investigation.

The security environment is intentionally separated from the primary client and server networks.

The overall objective is to understand the relationship between:

Infrastructure
      ↓
Attack Surface
      ↓
Telemetry
      ↓
Detection
      ↓
Investigation
      ↓
Response
      ↓
Validation
